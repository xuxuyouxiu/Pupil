# 用户故事 — 宠物互动（摸头 / 戳戳 / 星星眼 / 状态播报气泡）

**版本：** v1.0
**状态：** 已确认（用户逐项选定）
**创建日期：** 2026-08-26

---

## 背景与现状

Pupil 悬浮球已具备 GrokBot 式生命感（眼神跟随、待机张望歪头、三点加载、感叹号等），
但**只看不摸**——用户与球没有任何互动通道；任务状态变化也只有声音和系统 Toast，
缺少「球自己在说话」的轻量表达。

**目标**：把球从「监控仪表」变成「可以撸的桌面宠物」，同时保持 GrokBot 原版的设计纪律
（形态切换藏进眨眼、缓动不回弹、球体永远是正圆、不加外部零件）。

**明确不做**：
- 不加新进程/新窗口（气泡复用球窗向上扩的 20px）
- 不做自由对话气泡（只做固定文案状态播报）
- 不动现有手势语义（单击面板 / 双击跳转 / 右键菜单 / 拖动）

---

## US-001 长按摸头（P0）

**作为** 把 Pupil 当桌宠的用户，**我想** 按住球不动时它在享受被摸，**以便** 工作间隙有治愈感。

**验收标准：**
1. Given 按住左键且移动 ≤4px，When 持续 450ms，Then 进入摸头态：眯眼 + 脸红淡入 + 头部轻晃 + 呼噜音效
2. Given 摸头持续 ≥2.5s，When 仍按住，Then 切爱心眼♥ + 小心心从球顶飘出
3. Given 松开或拖动，When 任一发生，Then 500ms 内回到原状态（切换藏在眨眼里）
4. 摸头期间眼神不跟随光标、不眨循环眼

## US-002 连点戳痒（P0）

**作为** 喜欢逗猫式交互的用户，**我想** 快速连点球会有反应，**以便** 闲时有东西可玩。

**验收标准：**
1. Given 单次快速点击，Then 球体轻微压扁弹回（无过冲）+ 戳音效
2. Given 900ms 内累计 3 次点击，Then 晕圈眼@_@ + 发昏摇晃 1.4s 后眨眼恢复
3. 双击跳转功能不受影响（双击仍触发跳转；三连点才触发晕圈）
4. 拖动不误触戳戳（移动超 4px 即取消计数）

## US-003 完成星星眼（P0）

**作为** 等结果的用户，**我想** 任务完成时球用星星眼庆祝，**以便** 一眼确认「成了」。

**验收标准：**
1. Given 聚合展示态变为 done，Then 双眼为白色四角星✦并缓慢闪烁（替换现 wink）
2. 弹跳、两侧星光、完成音效全部保留
3. 形态切换藏在一次眨眼内（沿用 eye-swap 机制）

## US-004 状态播报气泡（P0）

**作为** 多任务并行的用户，**我想** 球用一句话告诉我发生了什么，**以便** 不切窗口就知道该不该回头处理。

**验收标准：**
1. 展示态边沿触发：idle→done「搞定啦✓」、任意→waiting「该你啦～」、任意→error「呜…炸了」
2. 同一文案 1.2s 内不重复弹出；持续态不复读（只在变化瞬间说一次）
3. 气泡 2.8s 自动消失；悬停气泡上暂停消失，移开继续
4. 勿扰模式开启时不弹任何气泡
5. 气泡出现在球正上方（窗口向上扩 20px），不加进程不加内存
