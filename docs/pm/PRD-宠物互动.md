# PRD：宠物互动（摸头 / 戳戳 / 星星眼 / 状态播报气泡）

**版本**：v1.0
**日期**：2026-08-26
**状态**：已确认（用户选定：两个手势都做 + 状态播报气泡 + 全部四个新表情）

## 1. 背景与目标

### 1.1 背景
悬浮球已完成状态表达（v0.4.x 六态变形动画）与生命感（眼神跟随、待机张望），
但用户与球零互动；任务状态变化依赖音效+Toast，缺一个「球在说话」的轻量层。

### 1.2 目标用户
| 角色 | 特征 | 核心诉求 |
|---|---|---|
| Pupil 日用主人（单一用户） | 多 Agent 并行监控，把球当桌宠 | 摸得到、有反应、会报喜报忧 |

### 1.3 成功指标
- 摸头/戳戳触发准确率 100%（不误触单击/双击/拖动语义）
- 气泡只在状态变化瞬间出现一次，零复读
- 进程数与内存不变（气泡复用球窗）

## 2. 功能需求

### 2.1 手势仲裁器 `petting.ts`（renderer，纯函数可测）
统一裁决四类左键手势，替代现在分散的 onClick/onDoubleClick：

| 手势 | 判定 | 动作 |
|---|---|---|
| 单击 | up 后 260ms 无后续点击 | togglePanel |
| 双击 | 260ms 内第 2 击 | activateWindow（保留现语义）|
| 三连点戳戳 | 900ms 窗口内第 3 击 | poke 反应（晕圈眼+摇晃 1.4s）|
| 长按摸头 | down 后持续按住且移动 ≤4px 达 450ms | petting 开始；松开结束 |

- 移动 >4px → 取消所有待定判定（是拖动）
- 长按进行中松开 → 只算摸头结束，不再触发单击面板
- 戳戳每次点击都给即时反馈（压扁弹回），第 3 击追加晕圈态
- 双击跳转保持即时触发（不加延迟）；三连点的第 1、2 击即双击，跳转照常发生，
  第 3 击才进入被戳烦——用户逗球时多跳一次面板属预期代价（已确认方案）
- 输出事件流：`{ type: 'click' | 'double' | 'triple' | 'petStart' | 'petEnd' }`

### 2.2 新表情（EyeSystem 扩展 `mood` prop + Ball 覆盖层）
| mood | 触发 | 视觉（对齐 bloub 测量纪律） |
|---|---|---|
| petting | 长按 450ms 起 | 眯眼享受（原版 egg 态眼 0.164×0.385 收敛版）+ 头部 ±4° 轻晃 + 脸红两枚淡入 |
| loved | 摸头 ≥2.5s | 爱心眼♥ + 心心从球顶飘出（每 900ms 一颗） |
| dizzy | 三连点后 1.4s | 晕圈眼@_@（白圈圈眼）+ 发昏小幅摇晃 |
| stars | done 态 | 双眼白色四角星✦缓慢闪烁（替换 wink；星光/弹跳保留）|

- 所有形态切换沿用 `.eye-swap` 眨眼遮蔽；缓动 ease-out 不回弹
- 脸红 = 黑球上两枚低饱和粉椭圆（`#e8a0a8` @ 0.5），唯一新增颜色元素
- mood 优先级：dizzy > loved > petting > 状态表情；结束后自动回落并眨眼过渡

### 2.3 音效（sound.ts 扩展，Web Audio 合成，不走通知策略）
- purr：呼噜——低频 55Hz 正弦 + 24Hz 幅度颤音，循环至摸头结束（独立 gain 可停）
- poke：短促「啵」——880Hz 上滑 1200Hz，60ms
- 音量跟随全局 soundVolume；总静音(muted)时同样静音

### 2.4 状态播报气泡（Ball.tsx 内渲染 + 主进程边沿检测）
- **主进程 MonitoringCore 订阅回调里做聚合展示态边沿检测**
 （快照全量广播、无逐事件流，且天然聚合+去重），命中规则发 IPC：
  - idle→done：「搞定啦✓」；任意→waiting：「该你啦～」；任意→error：「呜…炸了…」
  - 同文案 1.2s 去重窗口；勿扰开启时不发
- renderer 在球窗顶部 20px 渲染气泡：黑底(90%)白字圆角条，淡入淡出各 150ms
- 窗口创建改为 height=BALL_SIZE+BUBBLE_BAND=76，球体 SVG 绝对定位在下 56px；
  ballPosition 存储语义不变（仍为球心区域原点），拖动/面板锚点换算 +20px 偏移
- 悬停气泡暂停消失计时，移开继续（纯 CSS :hover + JS 计时器配合）
- 2.8s 自动消失

## 3. 非功能需求
1. 零新进程/零新窗口；内存增量目标 <2MB
2. 所有动画 CSS 实现，遵循 prefers-reduced-motion 例外（本机已关动画，守卫禁写）
3. 手势仲裁纯函数化，vitest 覆盖：单击/双击/三连点/长按/拖动取消/长按吞单击
4. 气泡边沿检测纯函数化，vitest 覆盖：三类触发/去重/勿扰

## 4. 上线计划
v0.5.0（minor：新交互能力）。打包后真机验证四件套后提交打 tag。

## 5. 风险与依赖
- Windows 透明窗口点击命中=不透明像素，气泡带文字必然可 hover（无需穿透 IPC）✓ 已验证机制
- 三连点与双击的语义重叠：接受「逗球时可能先触发跳转」（第 1、2 击即双击）
- 拖动记忆位置兼容：旧配置 y 值需 +20px 迁移（读入时补偿一次）
