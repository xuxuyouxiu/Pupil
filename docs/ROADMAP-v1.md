## 明确不做（本期）

- 会话详情大视图（信息密度收益低、面板形态约束大）
- macOS/Linux 移植（win32 依赖是核心链路，成本远超收益）
- 跨设备同步/云（本地优先是产品红线）

## 风险与依赖

- 1.1 需真机验证 NSIS /S + runAfterFinish 实际行为（文档结论不可靠）
- 2.1 各源推断逻辑需真实会话数据回归（本机有 claude/codex/hermes/zcode 四源可用）
- 4.1 electron-updater 与自研镜像链的兼容策略：CDN feed 放 latest.yml，GitHub 作 fallback provider
